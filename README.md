# HiRAGAMAJi - Romaji para Hiragana

O HiRAGAMAJi permite converter aliases de um voicebank de Romaji para Hiragana, com foco em arquivos de configuração `oto.ini` para UTAU. A ferramenta facilita a padronização de dicionários e oferece controle total sobre as edições.

## Funcionalidades

* **Conversão em Lote**: Transforma automaticamente entradas em Romaji para o equivalente em Hiragana.
* **Edição em Tempo Real**: Interface com tabela editável para ajustes manuais imediatos.
* **Inferência de Alias**: Se o campo de alias estiver vazio, o sistema utiliza o nome do arquivo como base para a conversão.
* **Filtro de Busca**: Localização rápida de arquivos ou aliases específicos dentro de listas extensas.
* **Privacidade e Velocidade**: O processamento é feito inteiramente no navegador do usuário, sem envio de dados para servidores externos.

## Instruções de Uso

1. **Carregar**: Arraste o arquivo `oto.ini` para a tela ou utilize o botão de upload.
2. **Converter**: Clique no botão "Converter aliases" para processar todas as linhas.
3. **Revisar**: Utilize a tabela central para conferir os resultados e editar manualmente se necessário.
4. **Exportar**: Clique em "Baixar oto.ini" para salvar o arquivo final atualizado.

## Detalhes Técnicos

* **Sokuon**: Suporte para consoantes duplas (ex: "tte" vira "って").
* **N isolado**: Tratamento específico para a letra "n" ao final de sílabas ou antes de outras consoantes.
* **Compatibilidade**: Funciona em qualquer navegador moderno.
